# Blueprints

The founding design documents. Written before the code, revised as the plan
changed. Never edited in place - a revision is a new file that states what it
supersedes.

- `is-this-real-debrecen-trust-layer-blueprint-v1.0.md` - the original blueprint.
- `is-this-real-blueprint-v1.1-recommendation-integrated.md` - integrates the
  post-v1.0 recommendation review.
- `is-this-real-blueprint-v1.2-provenance-rename.md` - current. Renames the
  product from "Is This Real" (retained only as the spoken demo hook) to
  **Provenance**.

Read v1.2 first; it carries forward everything from v1.0/v1.1 still in force and
states explicitly where it departs from them.
