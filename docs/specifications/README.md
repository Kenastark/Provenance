# Specifications

Formal specification documents derived from the repository as it stands, rather
than design documents written ahead of the code (those live in
`docs/blueprints/`). Never edited in place - a revision is a new file that states
what it supersedes.

- `Provenance-SRS-v1.0.docx` - IEEE 29148-aligned Software Requirements
  Specification (85 pp.), generated from a structured review of source code,
  tests, CI, and the documentation set. Every functional/non-functional
  requirement is annotated with its implementation status (Implemented /
  Partially Implemented / Proposed-Future) and the repository evidence that
  supports it.
